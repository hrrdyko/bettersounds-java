# Better Sounds (Fabric, Minecraft Java 26.3)
Suara Better Sounds (asli Bedrock oleh MSAB14) + suara saat melempar item.
Suara dibundel di `sounds-assets.zip` dan diekstrak otomatis saat build (lihat .github/workflows/build.yml).
Build lokal: ekstrak `sounds-assets.zip` ke `src/main/resources/`, lalu `gradle build` (JDK 25).
